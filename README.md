# 高速影像分析工具（包装机卡料分析）

纯前端（Vite + TypeScript）的高速相机 BMP 序列分析工具，所有图像与数据均在浏览器本地处理，不上传任何文件。面向包装机推杆卡料场景，完成从序列载入、播放、反光标记点亚像素追踪，到位移/速度/加速度曲线分析与卡料前异常回弹的凸轮相位角定位。

## 功能与需求对照

| # | 需求 | 实现 |
|---|------|------|
| 1 | BMP 按文件名纳秒时间戳排序，跳变自动分段 | `src/core/sequence.ts`：数字段自动识别（≥16 位按 ns 时间戳），相邻时间差 >10× 中位帧间隔即切分新段 |
| 2 | 循环缓存覆盖段按文件序号回绕重建 | 同文件：检测序号下降切轮次；**有时间戳时按时间戳完整恢复全部帧**，无时间戳时按"槽位未被后续轮重写"的覆盖语义保留幸存文件 |
| 3 | 推杆反光片点选后逐帧亚像素质心 | `src/core/tracker.ts`：ROI 阈值分割 + 4 邻域连通域 + 灰度加权质心，匀速预测搜索窗，丢点自动扩窗重捕获 |
| 4 | 像素→毫米标尺标定 | `src/core/calibration.ts`：画面标尺两端点选 + 已知长度，两点定标 |
| 5 | 位移/速度/加速度曲线，差分后平滑 | `src/core/signal.ts`：PCA 主运动方向投影，Savitzky-Golay 卷积同时给出平滑位置与一/二阶导，边界局部多项式拟合 |
| 6 | 找出卡料前异常回弹并报凸轮相位角 | 速度过零检测回弹方向反转，低速持续段判定卡料停滞，取卡料前最后一次回弹，结论面板报出起始帧与凸轮角 |
| 7 | 导入 PLC 凸轮角度表按时间对齐，横轴可切凸轮角 | `src/core/camTable.ts`：CSV 两列，ns/ms/s 自动识别，360° 自动解卷绕，线性插值到每帧；偏移量可调；曲线横轴时间/凸轮角一键切换 |
| 验收 | 合成已知轨迹序列，追踪误差 <1 像素 | `src/core/synth.ts` 生成高斯反光斑 + 标尺 + 回绕/跳变场景；实测 **RMSE 0.084 px、最大 0.134 px** |

## 快速开始

```bash
npm install
npm run dev        # 开发，浏览器打开提示的本地地址
npm test           # 32 个单元测试（BMP/序列/追踪/信号/端到端算法）
npm run build      # 类型检查 + 生产构建到 dist/
npm run e2e        # Playwright 浏览器端到端（需先 npm run dev）
```

### 操作流程

1. **序列载入**：点"选择 BMP 序列"多选整个目录；或点"载入合成测试序列"一键生成带已知真值的演示数据（自动带入标尺标定与凸轮表）。
2. **播放**：播放/暂停、0.25×–10× 倍速、滑块逐帧；帧经 Web Worker 后台解码并 LRU 缓存。
3. 点"点选标记点"后在反光片上点一下 → "开始追踪全部帧"。
4. 需要物理量时，点"点选标尺两端"在画面标尺上各点一下，填入毫米长度后生成标定。
5. （可选）"导入角度表 CSV"，格式为每行 `时间,角度`，表头/注释行自动跳过；用"时间对齐偏移"对齐影像与 PLC 时钟。
6. 调整 SG 窗口、卡料/回弹阈值后点"运行分析"，在结论面板查看回弹凸轮相位角，可切换凸轮角横轴并导出 `analysis_result.csv`。

### 文件名约定

宽松匹配，无需固定前缀，例如均可：

```
cap_000123_1699999999999999999.bmp
frame_456_t1700000000000000000.bmp
img_000007.bmp                # 只有序号也可载入，但无法做时间戳分段
```

16 位及以上数字段视为纳秒时间戳，其余数字段的最后一个视为文件序号。

## 架构

```
src/
├─ core/                  # 纯算法，不依赖 DOM，可独立单测
│  ├─ bmp.ts              # 8/24/32 位 BMP 解码 + 8 位灰度编码（合成序列用）
│  ├─ sequence.ts         # 文件名解析 / 回绕重建 / 跳变分段 / 时间轴
│  ├─ tracker.ts          # 连通域 + 灰度加权亚像素质心跟踪
│  ├─ calibration.ts      # 标尺两点定标
│  ├─ signal.ts           # SG 平滑求导、PCA 主轴、回弹/卡料检测
│  ├─ camTable.ts         # PLC 角度表导入、解卷绕、插值对齐
│  └─ synth.ts            # 已知轨迹合成测试序列
├─ app/
│  ├─ frameWorker.ts      # Web Worker：解码与整序列追踪
│  ├─ frameStore.ts       # Worker 客户端 + LRU 帧缓存 + 播放预取
│  ├─ videoView.ts        # 画面 Canvas 与叠加层（质心/标尺/事件）
│  ├─ chartView.ts        # 三条曲线 Canvas，时间/凸轮角横轴
│  ├─ player.ts           # rAF 倍速播放
│  ├─ store.ts            # 发布订阅状态仓库
│  └─ app.ts              # 三栏界面与全流程接线
└─ test/                  # Vitest 单元测试 + Playwright 端到端
```

## 合成测试序列说明

240 帧 @1000 fps、320×200 灰度图，标记点脚本化运动：匀速推进 → 8 帧异常回弹（幅值 1.2 px）→ 恢复 → 40 帧卡料停滞 → 恢复；文件序号按模 64 回绕、第 80 帧后插入 25 帧时间戳跳变，同时生成 120 rpm（720 °/s）的 PLC 凸轮角度表。真值：回弹起始第 121 帧、凸轮角 86.4°、卡料起始第 161 帧。

## 已知边界

- BMP 仅支持未压缩的 8/24/32 位（BI_RGB / 标准 BI_BITFIELDS），RLE/JPEG/PNG 压缩会报明确错误。
- 无时间戳且发生多轮覆盖时，被后续轮重写的槽位无法恢复（信息已被相机物理覆盖），界面会在日志与分段列表中提示。
- 超大序列（数千帧以上）的整序列追踪在 Worker 中执行不卡界面，但内存占用与帧数成正比；播放解码走 LRU（默认 160 帧驻留）。
